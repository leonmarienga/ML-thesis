# Fixed protocol: target-blind six-band rule replacement v1

**Status:** exploratory diagnostic on known historical material, preregistered internally before this experiment's outcome calculations; not an untouched external holdout or a replacement of frozen Track A. This plan is fixed for the first run; log implementation-only fixes separately. No FY2025 access, no GitHub writes, no historical router prediction inputs.

**Question.** Can conservative, pre-specified, hazard-specific declaration metadata replace the four outcome-conditioned rule mechanisms without using the held obligation to choose eligible rows? "Replace" here means a new model with analogous evidence hypotheses, not reproducing the historical rules, cutoffs or class destinations.

**Source/cohort.** Pinned GitHub SHA `b0b6edb229d112dd6d11896a512bf1112414e4f6`, only `research/results/hazards/cohort_features.csv` (SHA-256 `319a45fc486dbf1dc07e3b7190256575cca9031144ecdac294d86b008f8b0e92`), FY2010–24, 912 non-Biological declarations. Use fixed existing historical obligation classes: <$100K; $100K–<$1M; $1M–<$50M; $50M–<$200M; $200M–<$500M; ≥$500M. Training labels only for model fit. Numeric amounts are not read; `actual_band` is loaded into a separate scoring/training label store after verifying the year roster. No prediction component receives held labels. Output predictions contain no labels.

**Forward split.** Fixed outer held fiscal years FY2019–24. Each year trains on earlier FYs only; additionally require the training event end (start if missing) to strictly precede the minimum of all held start and declaration dates and remove every training row in a held `event_group`. Group IDs are the pinned outcome-blind source-connected group incorporating known NOAA episodes, cyclone/fire/quake links and metadata overlaps. ID, FY and dates used for split/audit only, except expressly allowed feature transformations below; episode IDs are never model predictors. Later-origin training can use earlier-origin declarations, as in a rolling-origin backtest. Past final cumulative obligations and archived metadata do not have fully authenticated vintage timestamps; event grouping reduces but does not establish full physical independence. Do not interpret as prospective deployment evidence.

**Baseline.** Fresh pooled six-label multinomial L2 logistic model: fixed `C=1`, lbfgs, no class weights, max_iter=3000; predict posterior argmax with lowest ordered band on ties. Training-only one-hot of hazard, state, declaration type; annual cyclic encoding of incident-start month; log(1 + days from incident start to declaration), missing flag, training-only median imputation and standardization for delay. Negative delays count as missing. State, hazard and declaration type missing values handled as an explicit category. No labels/ID/year as predictors; no hyperparameter selection.

**Candidate.** Same model, augmenting the baseline with four fixed interaction terms: (i) Severe Ice Storm × declaration type (proxy for response declaration regime, not true mission or amendment dominance); (ii) Fire × standardized declaration elapsed time (not final incident or mission duration); (iii) Hurricane × declaration type (not an absence-of-mission test); and (iv) Hurricane × standardized declaration elapsed time (not amendment intensity). Categorical interaction columns reuse baseline's training one-hot for declaration type. Use a single fit per origin, no searches/threshold fitting, no special routing bands chosen based on examples. Deploy those probabilities only for the three target hazards when the independently fitted baseline's *predicted* band is below $50M; all other rows keep the baseline probabilities. The explicit predicted-band cap is fixed, not actual-label conditioning; above-$50M true cases misrouted by baseline remain eligible and are scored. A candidate may route an eligible row upward. No end dates, mission date/identity, counts, costs, missing-mission flags, amendments, settlements, final duration, title, program flags, revised geography, physical measurements or fund-related values as predictors. Current archived categories/dates plausibly available at declaration but historical versions/publication times are *not* independently certified. T0/T72 mission dates in the repository do not establish first observability, and its archived sources do not validate direct substitution of amendment/duration terms. Coverage reports will distinguish available metadata, gate-eligible rows and actual route changes.

**Checks and analysis.** Freeze the design without scoring; execute once on complete matched cohort. Verify feature allowlists, cohort/years/no held group crossing, withheld labels excluded from fit for every run; perturb held labels once per origin by deterministic permutation and once by deterministic class reassignment, rerun preparation/fit/prediction, assert exact equality of all predictions/probabilities including output hash. Score public historical labels only after checking that invariance. Predesignated primary estimand: pooled six-class macro-F1 difference candidate minus baseline; report 95% percentile intervals from 10,000 paired source-connected episode bootstrap replicates (all six classes retained and zero-denominator metrics defined as zero). Secondary: accuracy, ordinal absolute band error, multiclass Brier, per-class counts/recalls and confusions, >=$50M and >=$200M dichotomous recall (when support exists), per-year metrics, targeted hazard and gate eligibility. Explicitly report any actual >=$50M cases affected without letting those outcomes drive the gate. Informational criteria for independent replication: positive lower primary CI bound, no degradation of either upper-threshold recall, and ≥10 changed episode groups. No promotion against Track A from this development population; negative/null results preserved with no post-scoring retuning.
