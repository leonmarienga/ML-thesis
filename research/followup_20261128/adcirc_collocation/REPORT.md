## Executed archive check

The [Zenodo 2011–2021 NetCDF](https://zenodo.org/records/17905131) is 4,860,934,085 bytes. Three additional exact HTTP 206 ranges (196,608 bytes) exposed array metadata and coordinate data; 327,680 total bytes (0.00674%) were sufficient for the combined metadata and coordinate probes, including the two ranges already preserved by the prior index check. The coordinate replay alone needs 262,144 bytes. No publisher full-file checksum verification is implied by the local SHA-256 checks. The archive contains 12,536 finite longitude/latitude coordinate pairs (12,238 distinct positions in float representation); duplicate coordinates should not be treated as independent sites. `zeta` has shape `(75,426,12536)` (storm, time, archive node), gzip chunks `(20,100,2000)`, units metres and fill value −999. Thus a single zeta chunk can span multiple storms; preserve explicit event selection if reading it in a future batch. The file lists no triangulation, bathymetric depth, connected mesh element, or wet/dry state array. This is a 12,536-point extraction archive, not the 337,263-node full model described in the [publisher’s methods](https://www.nature.com/articles/s41597-026-07635-z).

## Official chart land-intersection screen

The exploratory NOAA CUSP mirror returned an empty Vaca Key query result, which is not evidence of a clear path. The official [NOAA ENC Direct to GIS](https://www.nauticalcharts.noaa.gov/learn/encdirect/) harbor and approach Land Area layers were used instead. Both layers returned nearby land features (local coverage positive control). For each fixed gauge, both layers flag a land intersection along the straight gauge-to-nearest-node segment. The rule is a geospatial screening veto on blind nearest-neighbor extraction, not proof that no around-land hydrodynamic path exists; ENC is current marine chart data, not a fixed 2017 shoreline or the ADCIRC mesh. No no-intersection result would by itself prove a wet or same-basin path. All four station-by-layer checks retain one intersection after trimming 5% off each endpoint, so the flag is not merely an endpoint touch.

## Datum and interpretation gates

The NetCDF's generic CF standard name for zeta refers to a geoid, but the [methods](https://www.nature.com/articles/s41597-026-07635-z) explicitly identify this model’s reference as Model Zero (MZ); the paper reports location-specific offsets up to about 0.4 m, not a universal correction. The [NOAA tidal-model manual](https://vdatum.noaa.gov/download/publications/Manual_2012.06.26.pdf) explains why model zero need not equal MSL. Local CO-OPS MSL and NAVD88 heights are relative to the respective station datum; neither station's published datum table supplies this particular model's MZ–MSL offset. Do not relabel MZ as NAVD88 or simply substitute regional VDatum values. Before physical validation, fix site-to-native-element selection from mesh and official time-appropriate water class/bathymetry only, establish canonical depth/datum and gauge co-exposure, document specific independent datum ties and associated uncertainty, then audit publisher model tuning/validation and prior thesis splits for site and storm overlap. If MZ offsets are unavailable, any exploratory relative-level comparison must predefine an independent non-event or training-only reference and demonstrate that the subtraction is invariant to constant offsets; this does not fix geometry, timing errors, scale differences, or the missing datum for absolute thresholds.

**Next options:** obtain the precise versioned full model mesh and station extraction evidence through already-authorized public sources, or screen other stations and multi-storm regimes by geometry before opening event responses. Do not relax the geospatial veto to rescue this Irma pair. Keep any eventual hindcast comparison retrospective: the model uses finalized best-track inputs. A land-water boundary screen does not validate overland depth, humanitarian need or funding. The previous negative synthetic-transfer result and the fixed authentic baseline remain unchanged. No independent held-storm validation or synthetic model improvement has been established.

## Reproduce

Install the pinned dependencies in a separate environment, then run `bash replay.sh`. It recreates and verifies `coordinates.json` and `enc_screen.json` from pinned inputs with no network. For the raw layout: `python -B layout.py`. Acquisition is opt-in: `python -B layout.py --fetch`, `python -B coordinates.py --fetch`, and `python -B enc.py --fetch`. HDF5 reads are bounded and require exact HTTP range responses; all requests used are public. NOAA CO-OPS station metadata is fetched via the two links above. `new_ranges.jsonl` and `enc_requests.json` preserve source URLs and transport evidence.
